# Contributing

Install requirements and run `npm test`. Use synthetic minimal fixtures. Do not commit customer applications, PLC exports, vendor resources, credentials, network inventories, or machine-specific acceptance evidence.

Keep engineering logic in `engine.py`, host contracts in `index.js`, discovery in the Windows bridge, and task guidance in SKILL.md/references. Update tool documentation with contract changes. Add regressions for meaningful failures.

Preserve exact application identity, preflight, real native qualification, and partial-failure evidence. Mock results only test logic. New native categories require retained real probes.

Describe the engineering problem, resulting behavior, validation, and remaining coverage in pull requests. Keep shared examples generic and distinguish static analysis, export comparison, visual review, build creation, and functional testing.
